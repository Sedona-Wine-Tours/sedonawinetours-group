# Guide form backend

`guide-form-Code.gs` is the Google Apps Script bound to the "Sedona Wine Tours Master Database" sheet
(project "Sedona Guide Tour Form"). It is kept here for version history only; the live copy is in the
Apps Script editor. To deploy: paste into Code.gs, save, Deploy > Manage deployments > edit > New version.
Nothing in this folder is published to the website (build.py copies only build/ into site/).
